# Toggleable Hoods Mod

Customizable hoods with toggleable positions for Minecraft players.

## Features

- Adds custom hood items to the game.
- Allows players to toggle between hood up and hood down modes by sneaking and interacting.

## Requirements

- Minecraft 1.20.4
- Fabric Loader 0.14.0 or higher
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/toggleable-hoods-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with Fabric Loader.

## Usage

1. Craft or obtain a hood item.
2. Hold the hood item in your main hand.
3. Sneak and interact to toggle between hood up and hood down modes.

## Configuration

The mod does not have a configuration file. The hood item can be customized by modifying the mod's code.
